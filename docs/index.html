FAQ

常见问题

Windows 提示「Windows 已保护你的电脑」怎么办？

这是 SmartScreen 对未签名程序的默认提示。点击「更多信息」，再点「仍要运行」即可。程序没有联网行为，也不写注册表。

macOS 提示「无法打开，因为无法验证开发者」？

在图标上右键，选择「打开」，再在弹窗里点一次「打开」。之后就不会再提示。

手机需要装 App 吗？

不需要。手机和电脑连同一个 Wi-Fi，扫码后直接在浏览器里操作，支持 iOS 和 Android。

公司内网、没有外网能用吗？

可以。只要设备在同一个局域网内，全程不需要访问互联网，数据也不会离开内网。

需要注册账号或者付费吗？

不需要。工具开源免费，没有账号体系，也没有付费墙。
